Enforce Section XIX (post-PR retrospective).
1. Read all review comments on the PR.
2. Group repeated mistakes.
3. For each group, propose the cheapest permanent fix: a lint rule, automated test, check, or skill line. Never add it to CLAUDE.md unless it passes both the Discoverability and Globality tests.
4. List skill rules that never fired as candidates for deletion.
