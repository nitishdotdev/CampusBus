Enforce Rule 4: grill before you plan.
1. Read the relevant code first. Do not ask what the codebase already answers.
2. Map the decision tree, biggest branch first.
3. Ask ONE question at a time. Give a recommended default answer with each question.
4. If a word is ambiguous, use the terms in CONTEXT.md. Ask which term the user means.
5. Questions that need a prototype go on a PARKED list. Do not guess them.
6. Summarize each resolved branch in 3 lines.
7. Write NO plan and NO code until the user replies "we're aligned".
